上海，一个全日制员工，拿最低工资。

人社部2026年10月发布的最新表格里，上海月最低工资是2740元，全国第一。
 
这个人到手2740，老板要掏多少？5472。
 
中间差的2732元，一分不少，全进了社保。老板掏出来的每一块钱，将近一半（49.9%）没到工人手里。
 
再去这座城市的另一头。月薪50万的人，老板付509,697，他到手290,231，社保加个税一共拿走43.1%。
 
穷人49.9%，富人43.1%。
 
然后有人告诉你，这个叫"福利"。

## 一、先把名字摆正
 
说社保不是税的人，理由就三条：法律上它叫"费"；钱进社保基金，专款专用，预算单列；你交了，退休能领。
 
这三条我都认。它确实叫费，确实单列。可一个东西叫什么，和它是什么，是两回事。拿四件事对一下。
 
**躲不掉。** 2025年9月1日起施行的最高法《劳动争议司法解释（二）》，第十九条写得明白：公司和员工私下约好不交社保，无效；员工自己写个承诺说不要社保，也无效；公司没交，员工可以解除合同，要经济补偿。《社会保险法》另有规定，欠缴的按日加收万分之五滞纳金。你想放弃，法律不让；你想少交，法律也不让。强制，是税最核心的特征。
 
**税务局在收。** 2018年的国税地税合并方案定了，2019年1月1日起，各项社保费统一交税务部门征收。中间缓过一阵，2020年11月起，包括上海在内的多地税务部门正式开征。
 
**国际上按税算。** OECD每年出一本《Taxing Wages》，里面的"税"，包括个人所得税，也包括员工和雇主缴的社保。它的核心指标叫税楔：企业用工成本和员工到手工资之间的差额，占用工成本的比例。你想要的"必须站在企业视角算"，OECD早就是这么算的。它最新的数字是35.1%，对象是单身、无子女、拿平均工资的人，OECD平均，2025年。
 
**对价很弱。** 单位交的16%进统筹池，不记在你名下；你个人账户里，只有你自己交的那8%。你多交一百，将来多领多少，看的是当地社平工资、缴费年限和整本公共账，跟你账户里躺着多少，没有直接关系。医保、失业、工伤是保险，保险费花在别人身上天经地义，这个我不争。但养老这块是大头，它的对价就是这么弱。
 
再看体量。2025年，企业养老保险基金收入5.9万亿，同年个人所得税收入1.62万亿。一项养老，是个税的3.6倍。（基金收入里含少量财政补助和投资收益，这里只做量级对照。）个税起征点每调一次，全网要吵一轮；社保这个3.6倍，被叫做"五险一金"，安安静静从工资里划走。
 
公式摆在这儿：
 
```
到手率   = 到手工资 ÷ 企业总成本
综合税率 = 1 − 到手率
```
 
企业总成本，是税前工资加上单位交的社保。税前工资里再扣掉个人社保和个税，剩下的才是到手。老板只认总成本这一个数，工资条上怎么分名目，是做给你看的。

## 二、穷人的税率，比富人高
 
先把参数摆出来。

然后看一组对照。
 
个税对穷人的态度：月收入5000元以下免征，还能再扣专项附加扣除。
 
社保对穷人的态度：你赚多少我不管，缴费基数最低按7546元算。
 
7546是个税起征点的1.51倍，是上海最低工资的2.75倍。工资低于这个数的人，不会少交，只会按这个数交。
 
另一头呢？个税对高收入者，最高45%，往上不封顶。社保对高收入者，基数封顶37731，超出的部分一分不收。
 
穷人设下限，富人设上限。方向和个税正好相反。

这张表，我只想指几个地方。
 
最低工资那一行，综合税率49.9%，比月薪50万的43.1%还高。员工在工资条上只看到被扣了22.4%，老板那边另掏的1939元，他看不见。同一个人，企业视角和个人视角，差了一倍还多。

再看社保一项占企业成本的比例。最低工资者49.9%，从下限到上限之间稳稳是28.8%，月薪5万掉到22.9%，10万掉到12.5%，50万只剩2.7%。一路往下，纯粹的累退。
 
个税想往回找平，但追不上。月薪50万的人，每个月交20多万个税，综合税率也只到43.1%，没追上最低工资者。
 
边际负担更有意思。每多发1元工资，企业多付的成本里，被社保和个税拿走多少：

| 7,600（刚过下限） | 30.9% |
| 12,577（社平） | 35.9% |
| 25,154（2倍社平） | 43.0% |
| 37,000（封顶线前） | 46.6% |

有两个算法对我的论点不利，说在前头。
 
**第一，把个人账户那8%当储蓄。** 有人说这8%是你自己的钱，将来要还给你，不该算税。行，我扣掉，重算：
 
| 档位 | 综合税率（8%算储蓄） |
|---|---:|
| 上海最低工资 | 38.9% |
| 月薪5000 | 30.7% |
| 上海社平工资 | 25.1% |
| 社保基数上限 | 32.0% |
| 月薪10万 | 33.2% |
| 月薪50万 | 42.5% |
 
虽然月薪5000那一档，30.7%，掉到了10万那档下面（所以"5000比10万税率高"这句话，只在社保全部算税的口径下成立），但是最低工资者依然比月薪10万的高5.7个点。
 
**第二，最低工资怎么读。** 上海规定最低工资不含个人缴的社保，所以我取"到手2740"，税前3532。如果把2740当税前工资，企业成本4679，到手1948，综合税率58.4%。我取的，是对我论点更不利的那个。
 
另外，这些是上海的数。"下限按社平工资60%、上限按300%"是全国统一的规矩，但各城市社平和最低工资的比例不同，别把表里的数直接搬到别的城市。

## 三、同一个制度，三套规则
 
公平这个词，放在社保上最刺耳。同样是退休，你领多少，取决于你是哪一类人。
 
| 群体 | 月均养老金 | 年份与出处 |
|---|---:|---|
| 城乡居民基本养老保险 | 204.7元 | 2022年，《中国劳动统计年鉴》 |
| 企业职工 | 3,148.6元 | 2022年，同上 |
| 机关事业单位 | 6,099.8元 | 2022年，同上 |
| 城乡居民（约1.8亿领取者） | 约246元 | 2024年，按基金支出与领取人数测算 |
| 城乡居民 | 约281元 | 2025年，按人社部统计公报数据测算 |
| 职工养老（企业加机关事业） | 约3,962元 | 2025年，同上 |
 
2022年那一组，企业职工是居民的15.4倍，机关事业单位是29.8倍。
 
省与省之间更夸张。澎湃援引搜狐城市的测算，2024年，城镇职工和城乡居民养老金的差距，上海只有2.3倍，云南23.4倍，西藏36.3倍。
 
财政也没一视同仁。2023年，国家财政对企业职工养老金的人均补贴是每月537.3元。而2024年全国城乡居民领到的全部养老金，平均才246元。财政补给一个企业退休职工的，是一个农民全部养老金的2.2倍。再对比2024年农村低保标准每月594元，居民养老金只有它的41%。
 
说到不公平，最能说明问题的，是"视同缴费"。
 
企业职工养老保险是1997年前后统一建立的。在这之前参加工作的老职工，那会儿没有个人缴费这回事，一分钱没交过。新制度来了，这些年份被"视同"缴过费：算进缴费年限，再配一份过渡性养老金。人没交钱，待遇照算。
 
没交的钱去哪了？变成了基金的窟窿。2017年国务院印发划转国有资本的方案，据当时的报道，方案和财政部的说明里自己就承认了：老职工在旧制度下无需缴费，新制度下视同缴费，形成了事实上的缺口。这个缺口，说明里讲有时代原因，有其合理性，但会留给年青一代。财政部的说法更直白：不填的话，缺口可能通过增加税收、提高在职人员缴费率，转移给下一代。
 
在职人员缴费率。就是你工资条上那10.5%，和你老板多掏的25.7%。现收现付的制度里，你这个月交的钱，这个月就发给了正在领的人，其中就有这笔历史账。
 
我不否认，老一辈当年工资被压得低，国家统收统支，补偿有道理，方案的说明里也这么讲。我不服的，是账单的收款对象。国家欠的账，今天由一个到手2740元、综合税率将近50%的年轻人来分担，凭什么？国资划转当然是对的方向，划10%的国有股权，中央层面到现在划了2.31万亿元。郑秉文2017年估计这个划转规模在几万亿。窟窿到底多大，没有一个公开统一的数，我不替官方编。但走到现在这个进度，账单还在往工资条上摊，这是事实。
 
再看体制内。2014年10月并轨之前，机关事业单位人员的养老金由财政包，个人一分钱不缴。据当时的媒体报道，机关事业单位养老金替代率在80%以上，个别到100%，企业职工在50%以下。并轨之后，个人才开始缴8%，同时有了职业年金，单位8%，个人4%。企业职工缴了一辈子，替代率不到五成；体制内不缴，八成起步。这套规则，能叫公平吗？
 
最后是没有老板的人。灵活就业的人交养老保险，要自己扛20%，上海的医保另加10%，缴费基数还得在社平的60%到300%之间选，不能低于7546。老板那一半不会消失，只是换成你自己掏。
 
## 四、你交的钱，大概率养不了你自己
 
先说清楚我的意思。我不是说国家会让养老金归零。该发的会发，这个国家不缺把钱发出去的本事。我的判断是：你将来拿到的那份，大概率比今天白纸黑字承诺的，来得更晚，缴得更久，领得更少。
 
人口这一页，没法吵。
 
| 指标 | 数字（2025年） |
|---|---|
| 出生人口 | 792万（2021到2025年：1062万、956万、902万、954万、792万） |
| 死亡人口 | 1131万，总人口减少339万 |
| 60岁及以上 | 32,338万，占23.0%，一年净增1,307万 |
| 65岁及以上 | 22,365万，占15.9% |
| 16到59岁 | 85,136万，占60.6%，是60岁及以上人口的2.63倍 |
 
2025年出生792万。同一年满60岁的那批人，出生在1965年，那一年出生2748万。进来的，是出去的28.8%。一年里60岁及以上人口净增1307万，比同年出生的婴儿多出65%。
 
缴费的和领钱的，现在是什么比例？
 
| 指标 | 数字 |
|---|---|
| 参保职工与离退休人员之比 | 2018年30,104万:11,798万，约2.55；2025年39,457万:15,215万，约2.59 |
| 职工基本养老保险基金（2025年） | 收入7.92万亿，支出7.12万亿，累计结余7.87万亿，约等于13.2个月的支出 |
| 其中企业养老保险基金（2025年） | 收入5.9万亿，累计结余7.3万亿 |
| 社科院《中国养老金精算报告2019—2050》基准情景 | 累计结余2027年见顶6.99万亿，2035年前后耗尽；2050年前后，几乎1个缴费者养1个退休者（缴费赡养率96.3%） |
 
2018年到2025年，这个比例几乎没动，有人拿它说事，说没恶化。别高兴太早。比例没恶化，是因为扩面：灵活就业全面放开了户籍限制，职工养老参保人数涨到了5.5亿，把更多人塞进了缴费队伍。扩面的空间是有限的。
 
社科院那份2019年的报告，后来被一路对冲：国资划转、全国统筹、扩面、财政转移支付。2025年底企业养老保险基金累计结余7.3万亿，比报告里的路径好看。可是好看，是补出来的。
 
规则这边，已经在收紧：
 
| 项目 | 以前 | 现在在改成 |
|---|---|---|
| 男职工法定退休年龄 | 60岁 | 63岁，2025年起用15年逐步到位 |
| 女职工法定退休年龄 | 50岁、55岁 | 55岁、58岁 |
| 按月领养老金的最低缴费年限 | 15年 | 2030年起每年加6个月，2039年到20年（2025到2029年退休的仍按15年） |
| 退休人员养老金年度调整 | 2023年3.8%，2024年3% | 2025年2%，2026年预算安排也是2% |
 
钱从哪来，就四条路：提高费率，降低待遇，延长年限，财政和国资来补。前三条都在走：退休年龄在拉长，缴费年限在拉长，调整幅度一年比一年低。第四条补进来的钱，也是税。
 
还有个人账户。你的账户里，写着你交的8%。多年来，个人账户记的是数字，现金是当期发给了当期退休的人。2015年，城镇职工养老保险个人账户的累计记账额是4.71万亿，郑秉文把这类"空账"称作隐性债务，要靠未来几十年分期支付。你查余额，屏幕上有数字，这个数字能不能兑现，得看那个"未来"。
 
所以才有标题里那句话：别把你交的钱，当成存在银行的存款。它是你交的税，国家怎么花，花在谁身上，是一件公共的事，不是你账户余额的事。

## 五、最像样的反驳，我一个个拆
 
**反驳一：养老金公式是累进的，穷人回报率更高。**
 
这条是真的，我认。基础养老金的计算，是（当地社平工资加上你本人指数化的缴费工资）除以2，乘以缴费年限，再乘1%。对低缴费者有倾斜：
 
| 缴费工资 | 缴费指数 | 每缴费1年，基础养老金（占社平工资） | 每1单位缴费基数的回报 |
|---|---:|---:|---:|
| 社平的60%（下限） | 0.6 | 0.8% | 1.33% |
| 社平的100% | 1.0 | 1.0% | 1.00% |
| 社平的300%（上限） | 3.0 | 2.0% | 0.67% |
 
下限那档的回报，是上限那档的2倍。这是整套制度里最累进的一环，我承认。
 
但三件事它回答不了。
 
一是门槛。要领这笔钱，得先缴够15年，2030年起往20年走。断缴的、灵活就业的、频繁换工作的，就是低收入者里最先被这条线卡下去的人。
 
二是活多久。公式的累进是按"每年领多少"算的，不是按"一共领多少"算的。收入越低，预期寿命通常越短，多数研究都是这个方向。浙大何文炯团队研究长护险发现过同样的机制：低收入群体在医疗和照护资源上处于劣势，预期失能存活时间更短，统一定额缴费会产生逆向再分配。
 
三是现金流。公式的好处要等30年后才兑现，综合税率将近50%的那份扣款，今天就在拿。对一个到手2740元的人，今天的钱，比30年后的承诺金贵得多。
 
学界的结论并不一致。基于2016年CFPS数据的研究发现，养老保险让居民财产分布的基尼系数下降了；另一批研究指出，缴费机制的累退性会削弱甚至逆转再分配效果。《经济学（季刊）》2024年一篇论文的标题就叫《累退的缴费，累进的收益》，它做的反事实实验，开出来的药方是：降低缴费基数下限。我站在后一边，但你应该知道，有前一边。
 
**反驳二：基金有好几万亿，没有亏空。**
 
有，我引的就是这些数。可账是补出来的：财政补贴、国资划转、全国统筹、扩面，一个都没少。职工养老基金累计结余7.87万亿，相当于13.2个月的支出，对一个一年净增1300万60岁以上人口的国家，这是一年出头的缓冲。今天没亏空，不等于账平了。社科院2019年的预测未必精确，趋势是明摆着的。
 
**反驳三：社保里还有医疗、工伤、失业，是保险。**
 
保险的部分，我不反对交。我反对的是，一套号称互助共济的制度，把最低收入者的负担率定到将近五成，同时给高收入者的社保封顶。
